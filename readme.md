# Обработка данных из Yandex Object Storage с помощью сервиса Yandex Apache AirFlow, используя мощности Yandex Data Processing.
Шаги для выполнения:
1. Создать бакет `bucket-for-etl` в Yandex Object Storage, загрузить в него тестовый CSV-файл.
2. Развернуть кластер Apache Airflow (Yandex Data Proc).
3. Создать DAG-файл для обработки данных и загрузить его в бакет.
4. Запустить ETL-процесс через Airflow.
