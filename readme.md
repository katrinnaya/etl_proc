# Создание Python-приложения для работы с Yandex Managed Service for YDB
## Шаги выполнения
1. Добавление сервисному аккаунту необходимых ролей
2. Создание авторизационного ключа
3. Создание базы данных YDB
4. Настройка Ubuntu для работы с YDB
5. Запуск приложения и проверка результатов

## Шаг 1
Добавляем сервисному аккаунта роль `ydb.editor` для управления YDB
## Шаг 2
Для сервисного аккаунта создаем API-ключ и сохраняем файл с ключом на локальную машину
## Шаг 3
1. Создаем кластер YDB с типом `Serverless`
2. Получаем параметры подключения и сохраняем занчения для дальнейшего подключения
   * `Endpoint`
   * `Database path`
## Шаг 4
Т.к. проект будет запускаться под Ubuntu, подготавливаем рабочую область
1. Обновляем пакеты и зависимости
2. Создаем директорию `ydb_project`
3. Скачанный ключ копируем в папку проекта
4. Создаем виртуальное окружение
5. Устанавливаем зависимости
6. Создаем файл конфигурации
7. Создаем файл со скриптом `.py`
## Шаг 5
Запускаем приложение командой `python3 app.py`
