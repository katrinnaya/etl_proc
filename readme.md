## 1. Запуск контейнера
```
docker run --name nifi \
  -p 8443:8443 \
  -v ~/etl_proc/hw_4:/opt/nifi/nifi-current/data \
  -d \
  -e SINGLE_USER_CREDENTIALS_USERNAME=admin \
  -e SINGLE_USER_CREDENTIALS_PASSWORD=ctsBtRBKHRAx69EqUghvvgEvjnaLjFEB \
  apache/nifi:latest
```
## 2. Работа с NIFI
UI: https://localhost:8443

## 3. Добавление драйвера в библиотеку 
1. Скачать локально файл ``` postgresql-42.5.0.jar ```
2. Найти ID контейнера с помощью команды ``` docker ps ```
3. Скопировать файл внутрь контейнера
``` docker cp /root/postgresql-42.5.0.jar <container_id>:/opt/nifi/nifi-current/lib/ ```
4. Перезапустить контейнер docker restart <container_id>
